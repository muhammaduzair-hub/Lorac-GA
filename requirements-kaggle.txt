# Kaggle / GPU environment.
#
# RULE: floors only (>=), never `==` and never an upper bound.
# The Kaggle image already ships CUDA torch, numpy, pandas, matplotlib, seaborn,
# transformers, datasets and accelerate. A floor that the image already meets is
# a no-op; an `==` or `<` bound forces a DOWNGRADE and breaks the image.
#
# Learned the hard way (M2): pinning numpy<2 here — a constraint that only local
# torch 2.2.0 needs — downgraded Kaggle to numpy 1.26.4 and broke ~20 image
# packages (jax, cupy, opencv, shap, rasterio, tifffile, ...), and can also pull
# in a CPU-only torch build.
#
# Reproducibility comes from the "env" block recorded in every results.json
# (torch / transformers / peft / datasets / numpy versions + CUDA device + git
# commit), not from freezing the Kaggle image.
#
# KNOWN KAGGLE PREFLIGHT (pip cannot express it, so it lives in the notebook):
#   !pip uninstall -y torchao
# peft>=0.19 raises ImportError when torchao is present but < 0.16 (the image
# ships 0.10), and the LoRA dispatcher hits that check for every adapted module.
# We never use torchao quantization, so removing it is the minimal fix.
#
# FederatedScope is NOT needed from M2 onward (Route B: our own FedAvg loop).

#   pip install -e third_party/FederatedScope --no-deps
